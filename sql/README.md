# Query sources

The default v0.3 workflow uses `historical/` and `screening_manifest.json`, restoring SQL from the Data Expectations discussion. A historical generated query is not evidence that it ran successfully at all sites. Private source snapshots and discussion links are kept outside the public repository; record every executable adaptation separately.

The earlier SQL pack remains supplemental. Do not silently mix its metric definitions with historical aggregates. Consult each query for its candidate selection, numerator, denominator, table dependencies and limitations. The runner substitutes the chosen schema, not clinical logic.
